# TECHPATH WAY 🚀

> **Your Tech Journey Starts Here.**  
> *Learn. Build. Grow.*

A modern, responsive frontend web platform designed for B.Tech and engineering students to discover their path in technology, prepare for high-impact software careers, and build practical skills.

---

## 🌟 Stage 1 — Starting Page
- **Clean Modern Navigation**: Placeholders for *Home*, *Roadmaps*, *Skills*, *Resources*, *About*, and *Live Path Progress*.
- **Main Starting Screen**: Prominent **TECHPATH WAY** branding, motivating headline, tagline (*Learn. Build. Grow.*), and interactive **Start Your Journey →** call to action.
- **Modern Tech Aesthetic**: Deep dark theme (`#07090e`), ambient blue/purple gradients, minimal glassmorphism, and responsive layout.

---

## 🛠️ Tech Stack
- **React 19**
- **Vite 8**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Lucide React** Icons

---

## 💻 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/saikrishnapandal480-spec/btech-career.git
   cd btech-career
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
